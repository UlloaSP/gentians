Respuestas directas

        
Lo importante: ejemplos solos no bastan salvo que uses bias automatico. Aun con bias automatico, conviene dar bias manual para controlar busqueda y evitar reglas absurdas o espacio enorme.

      


      

        

          
Le doy descripcion + positivos + negativos e infiere?

          
Necesita conocimiento base ejecutable ASP. La descripcion humana no se usa. Pos/neg dicen que atomos deben aparecer o no en algun answer set. Para inventar reglas necesita tambien bias manual o -alb.

        

        

          
Que son stubs?

          
Plantillas de regla con huecos _____. Ejemplo: odd(_____):- even(_____),prev(_____,_____).. Salen del bias, no de texto libre.

        

        

          
Yo digo que stubs puede usar?

          
No directamente en input normal. Dices predicados permitidos con #modeh y #modeb, operadores CLI y limites. El sampler arma stubs combinando eso.

        

        

          
Como se rellenan?

          
VariablePlacer crea otro programa ASP: posiciones, variables posibles, restricciones de seguridad, no variables solas, cabeza segura, simetrias. Clingo enumera asignaciones validas.

        

        

          
Como sabe que reglas usar?

          
No "sabe"; busca. Cada programa candidato se ejecuta con background + reglas. Se mide cuantos positivos cubre y cuantos negativos cubre. Mejor cobertura gana.

        

        

          
Que tiene preferencia?

          
Fitness: cubrir mas positivos, cubrir menos negativos. Si busca subset dentro de un individuo, coste menor: negativos - positivos. Empates favorecen subset mas corto.

        

      

    


    

      

        
Formato input

        
Archivo minimo: background ASP, ejemplos, bias. Agregados, comparacion y aritmetica van por CLI, no dentro del fichero.

      

      

        
# Background
even(0).
prev(1,0).
prev(2,1).
prev(3,2).

# Examples
#pos({odd(1), odd(3), even(2)}, {}).
#neg({even(3)}, {}).
#neg({odd(2)}, {}).

# Bias
#modeh(1, odd, 1).
#modeh(1, even, 1).
#modeb(1, even, 1, positive).
#modeb(1, odd, 1, positive).
#modeb(2, prev, 2, positive).

        
gentians -f tarea.lp \
  -d 3 \
  --variables 3 \
  -s 1000 \
  -c 6

# Bias automatico:
gentians -f tarea.lp -alb=1

# Negacion permitida en body automatico:
gentians -f tarea.lp -alb=-1

# Agregados:
gentians -e magic_square_no_diag \
  --aggregates "sum(x/3)" \
  --comparison neq
